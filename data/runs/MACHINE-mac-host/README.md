# Mac host (arm64)

Hardware of the Mac that produced the host runs (Table 2 of the paper), as
reported by the machine's System Information and supplied by the authors.
Only the fields below are recorded; serial numbers, hardware UUIDs and other
device identifiers are deliberately omitted.

| Field | Value |
|---|---|
| Model | MacBook Air (Mac16,12) |
| Chip | Apple M4 |
| Cores | 10 (4 performance + 6 efficiency) |
| Memory | 16 GB |
| OS | macOS 26.5.2 (also recorded in the runs' run_metadata.json) |

This file was not written by a run script: the run metadata of the Mac runs
recorded the OS version but not the model or core count.
